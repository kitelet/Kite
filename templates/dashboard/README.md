# Kite Dashboard Template

A modern, responsive administrative analytics and dashboard template built with Kite.

## Features

- **Sidebar Navigation**: Responsive sidebar component with hash routing.
- **Key Performance Indicator (KPI) Cards**: Reusable `<kite-use name="stat-card">` components.
- **Interactive Metric Models**: Real-time filtering, metric updates, and dynamic state management.
- **Zero Build Step**: Native HTML tags and declarative attributes.
