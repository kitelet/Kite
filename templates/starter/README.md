# Kite Starter App

A starter project demonstrating Kite's declarative MVCR architecture.

## Getting Started

```bash
# Start development server with live reload
npm run dev

# Compile production bundle in dist/
npm run build

# Preview production build
npm run preview

# Diagnose project health
npm run doctor
```

## Structure

- `public/index.html`: Main HTML shell.
- `app/models/`: Reactive state and logic.
- `app/views/`: Screen markup.
- `app/components/`: Reusable HTML components.
- `app/routes/`: Route definitions.
- `styles/`: Application styles.
