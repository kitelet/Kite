# Kite Full App

A complete Kite MVCR application with todos, user profile, and routing.

## Getting Started

```bash
npm install
npm run dev
```

## Structure

| Folder | Layer | Purpose |
|--------|-------|---------|
| `app/models/` | Model | Reactive state and business logic |
| `app/views/` | View | Screen markup |
| `app/controllers/` | Controller | Interaction handlers |
| `app/routes/` | Route | URL → view mapping |
| `app/components/` | Component | Reusable UI blocks |
| `app/api/` | API | Backend client config |
| `styles/` | — | Global and theme CSS |
