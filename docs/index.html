Engineered with Purpose

Kite is not another bloated framework. It is a focused teaching toolkit built on six inviolable foundations.

⚡

Zero Boilerplate

Drop one <script> tag into any HTML page. No build pipeline, no bundlers, no npm install required to begin.

🧩

Local-First Components

Declare templates with <kite-component> and instantiate them with <kite-use>. Isolated props and slot content projection.

🏛️

Visible MVCR in HTML

Models, Views, Controllers, and Routes are expressed as native HTML tags, not hidden behind opaque JavaScript runtime abstractions.

🔒

100% CSP Compliant

Zero eval() and zero new Function(). Custom recursive-descent expression parser operates safely under strict enterprise Content Security Policies.

🤖

Agentic-Ready Toolkit

Complete machine-readable layer (.kite/*.json, Draft-07 schemas, AGENTS.md) that lets AI agents write verified code on first contact.

⚖️

Honest Scale Limits

Explicitly documented sweet spots (<500 interactive nodes). When you outgrow Kite, dedicated graduation guides help you migrate cleanly.
